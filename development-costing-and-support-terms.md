## 2. Post-Launch Support & Revisions

### Warranty Period

**90-Day Warranty Period** (starts from production launch date)

During the warranty period, the following is included at no additional cost:

* **Bug fixes** for issues that prevent core functionality
* **Critical security patches** and vulnerabilities
* **Performance issues** that impact system usability
* **Data integrity issues** and database errors
* **Integration failures** with marketplace APIs or payment gateways

**Warranty Exclusions:**
* Issues caused by third-party services or API changes
* Problems resulting from infrastructure changes made by client
* Issues caused by unauthorized code modifications
* Feature enhancements or new functionality

---

### Free Post-Launch Support

After production launch, the following is included:

* **25 hours of free revisions / adjustments** (separate from warranty)
* Minor bug fixes (non-critical)
* Minor UI/UX refinements
* Small logic tweaks and adjustments
* Configuration changes
* Documentation updates

> These hours are intended to stabilize the system post-launch and ensure smooth adoption. Hours must be used within **60 days** of production launch.

---

### Retainer Package

**Single Retainer Package Available**

The retainer package includes:

* **25 free hours** of post-launch support/adjustments
* Free hours must be used within **60 days** of production launch
* After free hours expire or are consumed: **$25/hour** ongoing support rate
* Priority support included
* Work is billed only for approved tasks
* Hours are tracked and reported transparently
* Minimum billing increment: 0.5 hours

**Retainer Benefits:**
* Priority response times
* Dedicated support channel
* Transparent hour tracking
* Flexible support for post-launch adjustments

**Retainer Terms:**
* Free hours expire 60 days after production launch (unused hours are forfeited)
* After free hours: Standard $25/hour rate applies
* No monthly retainer fee (pay-as-you-go after free hours)
* Support work requires client approval before billing

---

### Ongoing Support (After Free Hours & Warranty)

Once the 25 free hours are consumed and warranty period expires:

* **Hourly Rate:** **$25 USD / hour**

**Support Response Times:**

**Support Hours:**
* Standard support: Monday–Friday, 9 AM–6 PM (client timezone)
* Emergency support: Available for critical production issues (additional rate applies)

**Examples of Billable Support Work:**

## 5. Change Management

### Scope Changes

Any changes to the original project scope will be handled through a **Change Request Process**:

1. **Change Request Submission:** Client submits detailed change request
2. **Impact Assessment:** Development team evaluates impact on timeline and cost
3. **Proposal:** Written proposal with updated timeline and cost (if applicable)
4. **Approval:** Client approves before work begins
5. **Implementation:** Changes implemented and billed separately

**Change Request Examples:**
* Additional features not in original scope
* Design modifications beyond minor refinements
* Additional marketplace integrations
* Extended functionality beyond MVP
* Timeline acceleration requests

### Timeline Adjustments

* Minor scope changes may be accommodated within the original timeline
* Significant scope changes may require timeline extension
* Timeline extensions will be discussed and agreed upon before implementation

## 6. Acceptance Criteria & Sign-Off

### Definition of "Production Ready"

The system is considered production-ready when:

* ✅ All features from the original scope are implemented and tested
* ✅ Security hardening is completed
* ✅ Load testing validates system capacity
* ✅ Testing and QA completed
* ✅ Documentation is complete
* ✅ Deployment is successful in production environment
* ✅ Monitoring and alerting are configured
* ✅ Client acceptance testing is passed

### Acceptance Process

1. **Internal QA:** Development team completes testing
2. **Beta Testing:** Limited beta testing with select users (included in Phase 4)
3. **Client Acceptance Testing:** Client reviews and tests all features
4. **Sign-Off:** Client provides formal acceptance
5. **Production Launch:** System goes live

**Acceptance Timeline:**
* Client has **7 business days** to review and provide feedback after delivery
* Any issues found during acceptance testing will be addressed under warranty
* Sign-off triggers final payment (50% remaining balance)
